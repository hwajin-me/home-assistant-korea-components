- 실제 flow→API 파서→등록→coordinator 첫 갱신까지 연결한 회귀 테스트

자동 테스트의 외부 API 응답은 모의 응답입니다. 로컬 HTTP 서버로 실제 aiohttp URL 인코딩과
공유 세션 유지도 검증했습니다. 이후 유효한 인증키로 의료 3종 API와 설정 흐름을
별도 검증했습니다([결과](LIVE_VALIDATION.md)). 원천 데이터는 공공데이터포털에 게시된 두 API의 명세를
기준으로 하며, 공공 API 자체는 실시간 진료/개점 정보가 아닌 인허가 상태입니다.

2026-09-21에는 별도로 실제 카카오 API에 쿠키 없이 요청하여 새 gate-token 발급,
검색 1/2페이지 이동 및 `서울특별시 용산구 라온동물병원`의 유일 후보 자동 매칭
(장소 ID 11558466), 상세 조회, 7일 시간표 해석을 검증했습니다. 계산한 상태는
조회 시점의 카카오 `OPEN` 표시와 일치했습니다. 카카오 웹 API는 비공식이므로
상시 가용성·향후 응답 형식·실제 현장 영업 여부를 보장하지 않습니다.
